# บัญชีคนในครอบครัว และหน้า "ผู้ช่วย AI"

วันที่: 2026-10-23

## เจตนาและเหตุผล

ตอนนี้ฟีเจอร์ MCP ใช้งานได้ครบแล้ว (ดู `docs/superpowers/specs/2026-10-21-farm-mcp-design.md`) แต่ผู้ใช้ไม่รู้ว่า Claude ที่เชื่อมกับสวนทำอะไรได้บ้าง เพราะสิ่งที่มีเกี่ยวกับ AI อยู่ในหน้า "ตั้งค่า → เชื่อมต่อ Claude" ซึ่งเขียนไว้สำหรับคนตั้งค่าเท่านั้น

เจ้าของ (ผู้ใช้คนปัจจุบัน) ใช้ Claude เป็นอยู่แล้ว และต้องการให้**คนในครอบครัว**ที่ยังไม่เคยใช้ Claude สามารถ**ถามข้อมูลสวนและบันทึกผ่านแชต**ได้ เจ้าของจะเป็นคนตั้งค่าการเชื่อมต่อให้เอง ส่วนคนในครอบครัวจะเข้ามาที่หน้านี้เพื่อดูว่าทำอะไรผ่าน AI ได้บ้าง

แต่ละคนต้องใช้**บัญชีของตัวเอง** เพื่อให้รู้ว่าใครเป็นคนบันทึก แต่ตอนนี้แอปยังสมัครสมาชิกไม่ได้และไม่มีหน้าเพิ่มผู้ใช้ มีเพียงบัญชีเจ้าของที่สร้างจาก seeder งานนี้จึงมีสองส่วน และต้องทำตามลำดับนี้

1. บัญชีคนในครอบครัว
2. หน้า "ผู้ช่วย AI"

## เป้าหมาย

- เจ้าของเพิ่ม แก้ ปิดหรือเปิดใช้งานบัญชีของคนในครอบครัวได้ และตั้งรหัสผ่านใหม่ให้ได้
- คนในครอบครัวเปิดหน้า "ผู้ช่วย AI" แล้วเข้าใจทันทีว่าพิมพ์อะไรใน Claude ได้บ้าง และอะไรที่ยังต้องทำในแอป
- เจ้าของเห็นและยกเลิกการเชื่อมต่อ Claude ของทุกคนได้จากหน้าเดียว
- บันทึกที่มาจาก AI บอกได้ว่าใครเป็นคนบันทึก

## Non-goals

- การสมัครสมาชิกเอง, การส่งอีเมลเชิญ และการรีเซ็ตรหัสผ่านทางอีเมล (แอปยังไม่ได้ตั้งค่าส่งอีเมล)
- ระบบสิทธิ์หลายระดับนอกจาก "เจ้าของ / สมาชิก" สมาชิกยังเห็นและแก้ข้อมูลทุกสวนได้เท่าเจ้าของ
- มีเจ้าของหลายคน หรือโอนความเป็นเจ้าของ
- หน้าโน้ตความรู้และหน้าถังขยะในแอป (ยังทำผ่าน MCP เท่านั้น ตาม lean cuts เดิม)
- การเปลี่ยนเครื่องมือ MCP หรือ instructions ของ server

## Anti-goals

- คนในครอบครัวเปิดหน้านี้แล้วยังไม่รู้ว่าจะพิมพ์อะไรใน Claude หรือเจอศัพท์เทคนิคอย่าง MCP, OAuth หรือ token
- ตัวอย่างประโยคในหน้าบอกว่าทำสิ่งที่เครื่องมือทำไม่ได้จริง เช่นแนบรูปเข้าบันทึก หรือเพิ่มต้น
- บัญชีที่ปิดใช้งานแล้วยังล็อกอินได้ ยังใช้ session เดิมได้ หรือ Claude ที่เชื่อมด้วยบัญชีนั้นยังอ่านหรือเขียนข้อมูลได้
- เจ้าของปิดบัญชีตัวเองหรือลดสิทธิ์ตัวเองจนไม่มีใครจัดการบัญชีได้
- สมาชิกเข้าหน้าหรือ route จัดการบัญชีได้ (แม้จะพิมพ์ URL เอง)

## ข้อจำกัด

- ข้อความที่ผู้ใช้เห็นเป็นภาษาไทยทั้งหมด รวม `aria-label` และ `sr-only` (ตาม CLAUDE.md)
- UI ต้องเป็นไปตาม `DESIGN.md` และใช้ component ที่มีอยู่ เช่น `Heading`, `EmptyState`, `useConfirm`, `CopyableUrl` (ย้ายออกมาจากหน้าเดิม) และ `Badge`
- ห้ามเพิ่ม dependency
- ทุกการเปลี่ยนแปลงต้องมี Pest feature test
- ระบบเก็บที่มาไว้แล้วในคอลัมน์ `created_by`, `updated_by`, `created_via` และ `updated_via` (`app/Support/Provenance.php`) ส่วนป้าย AI ปัจจุบันมาจาก `isFromAi()` ใน `app/Support/TreeTimeline.php`

## ส่วนที่ 1: บัญชีคนในครอบครัว (ผู้ใช้ยืนยันแล้ว)

- **มีเจ้าของคนเดียว** และเก็บความเป็นเจ้าของเป็นค่าที่บันทึกไว้กับบัญชี ไม่ได้ผูกกับอีเมล ตอน migrate ให้ตั้งบัญชีที่อีเมลตรงกับ `config('farm.owner.email')` เป็นเจ้าของ ถ้าไม่มีบัญชีไหนตรง ให้ใช้บัญชีที่ id ต่ำสุด ส่วน seeder (ซึ่ง `docker/entrypoint.sh` เรียกทุกครั้งที่ deploy) ให้สร้างบัญชีเจ้าของ**เฉพาะตอนที่ยังไม่มีเจ้าของ**เท่านั้น เพื่อไม่ให้การเปลี่ยนอีเมลของเจ้าของ หรือการตั้งอีเมลสมาชิกให้ตรงกับ `OWNER_EMAIL` ไปสร้างบัญชีใหม่หรือย้ายความเป็นเจ้าของ *(Claude ตัดสินใจ)*
- **มีแค่เจ้าของที่เห็นและใช้หน้า "ตั้งค่า → สมาชิก" ได้** โดยหน้านี้มี
  - รายการบัญชีทั้งหมด แสดงชื่อ อีเมล ป้าย "เจ้าของ" หรือ "ปิดใช้งาน" และบอกว่า Claude เชื่อมอยู่หรือยัง
  - ปุ่ม "เพิ่มสมาชิก" กรอกชื่อ อีเมลที่ใช้ล็อกอิน และรหัสผ่านเริ่มต้น เจ้าของจะบอกรหัสนี้กับสมาชิกเอง และสมาชิกเปลี่ยนรหัสได้เองในหน้า "ตั้งค่า → โปรไฟล์" ที่มีอยู่แล้ว
  - เมนูของแต่ละบัญชีมี แก้ชื่อหรืออีเมล, ตั้งรหัสผ่านใหม่ และปิดหรือเปิดใช้งาน
- **ใช้การปิดใช้งานแทนการลบบัญชี** เพราะบันทึกเก่ายังอ้างถึงผู้ใช้คนนั้น เมื่อปิดใช้งานแล้ว
  - ล็อกอินไม่ได้
  - session ที่ล็อกอินค้างอยู่ใช้ต่อไม่ได้
  - token ของ Claude ทุกตัวของบัญชีนั้นใช้ไม่ได้ทันที
  - เมื่อเปิดใช้งานกลับ สมาชิกล็อกอินได้อีก แต่ต้องเชื่อม Claude ใหม่
- **เจ้าของปิดใช้งานบัญชีตัวเองไม่ได้**
- **ป้าย AI ในไทม์ไลน์หน้าต้นบอกชื่อคนบันทึกด้วย** เช่น "AI · แม่" ชื่อในป้ายคือคนที่ใช้ AI ถ้าบันทึกนั้นสร้างผ่าน AI ให้ใช้ชื่อคนสร้าง ถ้าสร้างในแอปแต่แก้ล่าสุดผ่าน AI ให้ใช้ชื่อคนแก้ *(Claude ตัดสินใจ)* ส่วน "บันทึกล่าสุดจาก AI" ให้นับเฉพาะบันทึกที่สร้างผ่าน AI เหมือนเดิม และแสดงชื่อคนสร้าง

## ส่วนที่ 2: หน้า "ผู้ช่วย AI" (ผู้ใช้ยืนยันแล้ว)

**ตำแหน่ง:** เป็นเมนูหลักใหม่ชื่อ "ผู้ช่วย AI" ต่อจาก "สวน" และ "ค่าใช้จ่าย" ใน `mainNavItems` (`resources/js/lib/navigation.ts`) จึงขึ้นทั้งในแถบด้านข้างและแถบล่างบนมือถือ หน้า "ตั้งค่า → เชื่อมต่อ Claude" เดิมจะย้ายมาที่หน้านี้ ลิงก์ในเมนู settings ให้เอาออก ส่วน URL เดิมให้ redirect มาหน้าใหม่

**ทุกคนเห็น** (เรียงจากบนลงล่าง)

1. หัวเรื่อง "ผู้ช่วย AI" และคำอธิบายหนึ่งบรรทัดว่าคุยกับ Claude เพื่อถามและบันทึกข้อมูลสวนได้
2. สถานะการเชื่อมต่อของตัวเอง ถ้าเชื่อมแล้วให้บอกวันที่เชื่อม ถ้ายังไม่เชื่อมให้บอกให้ไปขอเจ้าของช่วยตั้งค่า
3. ตัวอย่างประโยคที่พิมพ์ใน Claude ได้ กดเพื่อคัดลอก แบ่งตามหมวด หมวดละ 2–3 ประโยค ได้แก่
   - ถามข้อมูล
   - บันทึก (การดูแล, สภาพต้น, ผลผลิต, การขาย, ค่าใช้จ่าย)
   - ดูซ้ำหรือติดตามปัญหา
   - ขอคำแนะนำ (อิงผลจริงของสวนและโน้ต)
   - จดความรู้
   - แก้ ลบ และกู้คืน

   ทุกประโยคต้องทำได้จริงด้วยเครื่องมือใน `app/Mcp/Tools` และใช้ภาษาพูดแบบคนในสวน
4. สิ่งที่ Claude ทำให้ทุกครั้ง ได้แก่ สรุปให้ยืนยันก่อนบันทึก แก้ หรือลบ, ใส่ป้าย "AI · ชื่อ" ในหน้าต้น, ลบผิดก็บอกให้กู้คืนได้ และไม่เดาอัตราผสมยา แต่จะให้ดูฉลากหรือถามเจ้าหน้าที่เกษตร
5. สิ่งที่ยังต้องทำในแอป ได้แก่ แนบรูปเข้าบันทึก (Claude ดูรูปในแชตได้ แต่เก็บรูปเข้าระบบไม่ได้), เพิ่มหรือแก้สวน ต้น ฤดูกาล และพิมพ์ QR
6. บันทึกล่าสุดจาก AI ของทุกคน พร้อมชื่อคนบันทึก (ต่อยอดจาก `RecentAiRecords`)

**เจ้าของเห็นเพิ่ม**

7. การเชื่อมต่อของทุกคน แสดงชื่อคน ชื่อแอป และวันที่เชื่อม กดยกเลิกได้ (ใช้ `useConfirm`) บัญชีที่ยังไม่ได้เชื่อมแสดงเป็น "ยังไม่เชื่อม" ส่วนบัญชีที่ปิดใช้งานไม่ต้องแสดง
8. ส่วนตั้งค่าการเชื่อมต่อ มีที่อยู่ MCP พร้อมปุ่มคัดลอก, คำเตือนเมื่อ URL ยังเข้าจากอินเทอร์เน็ตไม่ได้ (ย้ายมาจากหน้าเดิม) และขั้นตอนตั้งค่าให้คนอื่น โดยเน้นว่าตอนกดอนุญาตต้องล็อกอินแอปนี้ด้วยบัญชีของคนนั้น

สมาชิกที่ไม่ใช่เจ้าของจะยกเลิกการเชื่อมต่อของตัวเองไม่ได้จากหน้านี้ ต้องให้เจ้าของทำให้ ข้อนี้ผู้ใช้ไม่ได้ยืนยันตรง ๆ ให้ดู "ให้ผู้สร้างตัดสินใจเอง"

## ให้ผู้สร้างตัดสินใจเอง

- วิธีเก็บว่าใครเป็นเจ้าของ (เช่น คอลัมน์ boolean) และวิธีเก็บสถานะปิดใช้งาน (เช่น `deactivated_at`)
- จะบังคับสิทธิ์ด้วย Gate, Policy หรือ middleware
- วิธีกันบัญชีที่ปิดใช้งาน ทั้งตอนล็อกอิน (Fortify), session ที่ค้างอยู่ และ token ของ Passport
- ชื่อ route, controller และ path ของหน้าใหม่ แต่ต้องไม่ใช้คำว่า MCP ในข้อความที่ผู้ใช้เห็น
- ถ้อยคำของตัวอย่างประโยคแต่ละข้อ
- จะให้สมาชิกยกเลิกการเชื่อมต่อของตัวเองได้ด้วยหรือไม่ (ถ้าทำได้ง่ายก็ใส่ไว้ได้ ไม่ขัดกับความต้องการ)
- รายละเอียดหน้าตาให้เป็นไปตาม DESIGN.md และ mockup ใน `.superpowers/brainstorm/` (ไฟล์ `members.html` และ `ai-page.html`)
