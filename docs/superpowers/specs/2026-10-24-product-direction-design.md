# ทิศทางของโปรเจ็ค — Design

วันที่: 2026-10-24
สถานะ: อนุมัติแล้ว
เกี่ยวข้อง: `2026-10-21-tree-tracking-lean-redesign-design.md` (ข้อที่ขัดกันให้ใช้เอกสารนี้), `2026-10-21-farm-mcp-design.md`, `2026-10-21-tree-observations-design.md`

## เจตนา

โปรเจ็คเริ่มจาก ERP ทั่วไป แล้วตัดเหลือเป็นสมุดจดรายต้นบนมือถือ เอกสารนี้กำหนดว่าจะไปทางไหนต่อ เพื่อใช้เป็นเกณฑ์ตอนออกแบบฟีเจอร์ใหม่

> **ระบบจัดการสวนของเจ้าของคนเดียวที่มีหลายสวน ข้อมูลเป็นรายต้น และต่อกับ AI ได้ตั้งแต่แรก**
> แอปเก็บข้อมูลและถือกฎของสวน ส่วน Claude ใช้ข้อมูลนั้นวิเคราะห์ แนะนำ และจดบันทึกกลับเข้าแอป

## ผู้ใช้

- **เจ้าของ (developer):** ตั้งค่า จัดการข้อมูลหลัก แก้ย้อนหลัง และดูรายงาน ใช้เดสก์ท็อปเป็นหลัก
- **คนในครอบครัวที่ดูแลและทำสวนจริง:** ใช้ Claude ได้ ถามข้อมูลและจดบันทึกผ่าน Claude บนมือถือ เปิดแอปเพื่อดูข้อมูลและสแกน QR ที่ต้น

ทุกคนอยู่ภายใต้เจ้าของคนเดียว และมีบทบาทแค่ "เจ้าของ / สมาชิก"

## หลักการ

### 1. เดสก์ท็อปเป็นหลัก มือถือไว้ดู และจดผ่าน Claude

- **เดสก์ท็อป:** ทำได้ครบทุกอย่างในแอป ทั้งจัดการสวน ต้น และรายการต่างๆ แก้และลบย้อนหลัง กู้ข้อมูลที่ลบ ดูตารางและรายงาน หน้าใหม่ออกแบบสำหรับจอกว้างก่อน ใช้ตารางและหลายคอลัมน์ได้
- **มือถือ:** ทุกหน้าต้องเปิดดูได้และอ่านง่าย (responsive) หน้าต้นจาก QR ต้องดีบนมือถือเสมอ ฟอร์มบันทึกบนมือถือที่มีอยู่ตอนนี้ยังใช้ได้ต่อ แต่จะไม่ทำฟอร์มใหม่สำหรับมือถือเป็นหลัก
- **การจดในสวนให้ทำผ่าน Claude (MCP):** ทุกอย่างที่ต้องจดเป็นประจำในสวน ต้องมีเครื่องมือ MCP ให้จดได้

### 2. MCP คือจุดเด่น

- ตัวอย่างที่ต้องทำได้: คุยกับ Claude เพื่อวิเคราะห์สภาพสวนและหาปุ๋ยหรือยามาบำรุง แล้วสั่งให้ Claude จดการดูแลนั้นลงระบบได้เลยในแชตเดียวกัน
- ฟีเจอร์ข้อมูลใหม่ทุกตัวต้องมีเครื่องมือ MCP สำหรับอ่าน และถ้าเป็นข้อมูลที่จดในสวนต้องมีเครื่องมือสำหรับเขียนด้วย นอกจากนี้ต้องอัปเดตตัวอย่างในหน้า "ผู้ช่วย AI" ให้ตรงกับสิ่งที่ทำได้จริง
- กฎที่เกี่ยวกับความปลอดภัย เช่น ระยะปลอดสาร การหมุนกลุ่มยา และอัตราการใช้ ให้ server คำนวณ ห้ามให้ AI คิดเอง (ตาม spec MCP ข้อ 8)
- ทุกการเขียนผ่าน Claude ต้องทวนให้ผู้ใช้ยืนยันก่อน และต้องเก็บว่าใครเป็นคนบันทึก (ตามที่มีอยู่แล้ว)

### 3. โครงสร้างรองรับหลายพืช แต่ตอนนี้ใช้แค่ทุเรียน

- ต้องเพิ่มชนิดพืชเข้าไปใน schema และให้ seed ทุเรียนไว้เป็นพืชเดียว ผู้ใช้ต้องไม่ต้องตั้งค่าอะไรก่อนเริ่มใช้
- สิ่งที่ขึ้นกับชนิดพืชต้องผูกกับพืช เช่น รายการสิ่งที่พบ (โรค แมลง ระยะการเติบโต) และฐานความรู้เรื่องยา/ปุ๋ย
- ข้อความที่ระบุว่าเป็นทุเรียน เช่น instructions ของ MCP server, `SaveSale`, โลโก้ และตัวอย่างประโยคในหน้า "ผู้ช่วย AI" ต้องเปลี่ยนไปอ่านจากชนิดพืช หรือเขียนให้เป็นกลาง
- ยังไม่ทำ UI สำหรับจัดการหลายพืช และยังไม่ทำพันธุ์ เกรด หรือข้อมูลหลักแบบ ERP เดิม

### 4. คลังปุ๋ย/ยาเป็นฐานความรู้ ไม่ใช่ระบบสต็อก

- เก็บว่ายาหรือปุ๋ยแต่ละตัวคืออะไร อยู่กลุ่มไหน ระยะปลอดสารนานเท่าไร และใช้อัตราเท่าไรตามฉลาก เพื่อให้ server คำนวณกฎความปลอดภัย และให้ Claude แนะนำได้ถูก
- ไม่ตัดยอดเข้า-ออก ไม่มีจุดสั่งซื้อ และไม่คิดต้นทุนต่อหน่วย

## ปรับ roadmap ข้อ 2–5

| ข้อ | เดิม | ทิศใหม่ |
|---|---|---|
| 2 | แผนงานที่กดเป็นบันทึก | คงไว้ วางแผนบนเดสก์ท็อป และกดหรือสั่ง Claude ให้เปลี่ยนเป็นบันทึกได้ |
| 3 | คลังปุ๋ย/ยา | ฐานความรู้เรื่องยา/ปุ๋ย ผูกกับชนิดพืช (หลักการข้อ 4) |
| 4 | รวมค่าใช้จ่ายเข้าการดูแล | ทำได้แค่ผูกค่าใช้จ่ายกับการดูแล ไม่กระจายต้นทุนลงรายต้น |
| 5 | เกรดผลผลิต | ยังพักไว้จนกว่าจะรู้ว่าผู้ซื้อแบ่งเกรดอย่างไร |

ก่อนทำข้อ 3 ต้องทำงานใหม่ข้อ 0 ก่อน คือ **เพิ่มชนิดพืชเข้าโครงสร้าง** (หลักการข้อ 3) เพราะฐานความรู้เรื่องยาต้องผูกกับพืช

## เกณฑ์คัดฟีเจอร์

ก่อนเพิ่มฟีเจอร์ใหม่ ให้ถามว่า

1. ฟีเจอร์นี้ช่วยให้รู้ว่าต้นไหนหรือสวนไหนเกิดอะไรขึ้น หรือช่วยให้ Claude แนะนำได้ถูกขึ้นไหม ถ้าไม่ช่วยเลยให้ตัดทิ้ง
2. ถ้าเป็นข้อมูลที่จดในสวน จดผ่าน Claude ได้หรือยัง
3. ใช้ได้ครบบนเดสก์ท็อป และอ่านได้บนมือถือหรือยัง

## Non-goals

- หลายเจ้าของ หลายองค์กร (multi-tenant) หรือระบบสิทธิ์ละเอียดกว่า "เจ้าของ / สมาชิก"
- ระบบสต็อก บัญชี เงินเดือนคนงาน หรือการกระจายต้นทุน
- AI ที่สร้างเองในแอป หรือการจ่ายค่า AI API ฝั่งเรา (Claude ต่อเข้ามาผ่าน MCP)
- แอปมือถือแบบ native และการใช้งาน offline

## Anti-goals

ถ้าเกิดสิ่งเหล่านี้ ให้ถือว่าล้มเหลว แม้ระบบจะทำงานได้ก็ตาม

- งานที่ต้องจดเป็นประจำในสวนต้องเปิดแอปบนมือถือกรอกฟอร์ม เพราะไม่มีทางจดผ่าน Claude
- งานจัดการบางอย่างทำได้แค่ผ่าน Claude หรือ tinker แต่ทำบนเดสก์ท็อปไม่ได้ (ยกเว้นงานที่ตั้งใจให้ทำผ่าน Claude อย่างเดียว)
- หน้าเปิดบนมือถือแล้วอ่านไม่ได้ มีตารางล้นจอ หรือต้อง scroll แนวนอนทั้งหน้า
- Claude แนะนำอัตราหรือระยะปลอดสารเอง โดยไม่ได้ใช้ข้อมูลจากระบบ
- การเพิ่มพืชชนิดที่สองต้องย้ายข้อมูลครั้งใหญ่ หรือต้องแก้โค้ดที่เขียนตายตัวว่าเป็นทุเรียนกระจายอยู่หลายที่

## คำถามที่ยังเปิด (ตอบใน spec ของข้อ 0)

- จะผูกชนิดพืชไว้ที่สวน หรือที่ต้น เพราะสวนผสม เช่น ทุเรียนกับมังคุด มีจริง วิธีที่น่าจะดีคือตั้งพืชหลักไว้ที่สวน แล้วให้ต้นเปลี่ยนเองได้
- ฤดูกาลผูกกับสวนอยู่ตอนนี้ ถ้าสวนเดียวมีหลายพืช ฤดูกาลจะผูกกับพืชด้วยหรือไม่
